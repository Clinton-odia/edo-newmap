# Edo-NewMap: Automated Build Environment & Web Infrastructure

## Overview
Edo-NewMap is a heavily customized web infrastructure project built on the `_s` (Underscores) foundation. This repository demonstrates the implementation of a modern, automated build pipeline, dependency management, and structured environment configuration for PHP-based web applications.

The primary focus of this architecture is to ensure a scalable, highly optimized, and reproducible development-to-production workflow using industry-standard package managers and task runners.

## System Architecture & Technologies
* **Dependency Management:** Composer (PHP), NPM (JavaScript/Node.js)
* **Build Automation:** Task running and asset compilation via CLI / Gulp
* **Environment:** Designed for seamless deployment across standard Linux/Apache/Nginx web servers
* **Core Languages:** PHP, JavaScript, SCSS

## Environment Setup & Initialization

To replicate this environment locally, ensure you have Node.js and Composer installed on your system.

1. **Clone the repository:**
   `git clone https://github.com/Clinton-odia/edo-newmap.git`
2. **Install system dependencies:**
   `npm install`
3. **Initialize PHP dependencies:**
   `composer install`

## Build Pipeline Commands

This project utilizes a command-line interface to automate repetitive tasks, compile assets, and prepare the environment for deployment.

* `npm run build` - Executes the build script to compile and minify all SCSS and JavaScript assets for production.
* `npm run watch` - Initializes a watcher for real-time asset compilation during local development.
* `npm run lint:scss` - Audits stylesheet architecture for errors and best-practice formatting.
* `npm run lint:js` - Audits JavaScript logic for syntax errors and performance bottlenecks.
* `npm run bundle` - Packages the entire system into a deployable `.zip` archive, excluding unnecessary development dependencies (e.g., `node_modules`).

## Deployment Strategy
The compiled output generated by the build pipeline is optimized for deployment to cloud-hosted environments (e.g., AWS EC2 or Lightsail) or standard CI/CD deployment workflows.
